Quero criar uma plataforma web para gestão de marketing digital de um salão de beleza 
(serviços: cabelo, unhas, estética e outros). A plataforma deve automatizar a criação 
e publicação de conteúdo para Instagram e Facebook, usando agentes de IA para apoiar 
a criação de imagens, vídeos e textos.

CONTEXTO DO NEGÓCIO:
- Salão de beleza com serviços de cabelo, unhas, estética
- Público-alvo: [defina aqui, ex: mulheres 20-45 anos, região X]
- Tom de voz da marca: [ex: elegante, acessível, divertido]
- Frequência de postagem desejada: [ex: 4-5x por semana]

FUNCIONALIDADES PRINCIPAIS:
1. Upload e organização de fotos/vídeos brutos (antes/depois, bastidores, procedimentos)
2. Biblioteca de mídia com tags automáticas (tipo de serviço, profissional, data)
3. Editor de imagem/vídeo integrado (cortes, filtros, legendas, marca d'água/logo)
4. Templates de posts (feed, stories, reels) com identidade visual do salão
5. Calendário editorial com agendamento de publicações
6. Preview de como o post vai aparecer no Instagram/Facebook antes de publicar
7. Dashboard de métricas básicas (engajamento, alcance, melhores horários)

AGENTES DE IA NECESSÁRIOS:
1. Agente de Criação de Conteúdo: sugere ideias de posts com base em tendências do 
   nicho de beleza e no histórico de serviços realizados
2. Agente de Copywriting: gera legendas, hashtags e CTAs adaptados ao tom de voz da marca
3. Agente de Edição Visual: aplica ajustes automáticos em fotos/vídeos (cor, corte, 
   proporção para feed/stories/reels), sugere melhores enquadramentos
4. Agente de Curadoria: analisa as mídias enviadas e sugere quais têm melhor potencial 
   de engajamento
5. Agente de Agendamento/Estratégia: sugere os melhores dias/horários de publicação 
   com base no desempenho histórico

REQUISITOS TÉCNICOS:
- Stack: [defina, ex: Next.js + Node.js + PostgreSQL, ou o que preferir]
- Integração com APIs oficiais do Instagram Graph API e Facebook Graph API para 
  publicação e coleta de métricas
- Armazenamento de mídia: [ex: S3, Cloudinary]
- Autenticação segura para conexão das contas de redes sociais
- Interface responsiva (uso também pelo celular, já que fotos vêm do salão)

PRIORIDADES PARA A PRIMEIRA VERSÃO (MVP):
1. Upload de mídia + edição básica
2. Geração de legenda com IA
3. Agendamento e publicação automática no Instagram/Facebook
4. Calendário visual simples
